# مدار

منصة كورسات رياضيات للمرحلتين الإعدادية والثانوية (والبكالوريا المصرية). الطالب
يتصفح الكورسات، يشحن محفظته (InstaPay / محفظة إلكترونية / فوري)، يشتري الكورس،
ويتابع دروس الفيديو — ومالك المنصة يدير الكورسات والدروس وطلبات الشحن من لوحة
تحكم مدمجة.

## المميزات

- **كتالوج كورسات** بفلاتر (مرحلة، صف، نظام، مسار، مستوى رياضيات) وبحث.
- **تسجيل دخول وحسابات** بالبريد وكلمة السر، مع أدوار: طالب / مالك / أدمن.
- **محفظة داخلية** بدفتر حسابات append-only: شحن يدوي يوافق عليه الأدمن، شراء
  كورسات، وسجل معاملات كامل.
- **مشغّل دروس** يدعم YouTube/Vimeo/روابط فيديو مباشرة، مع دروس مجانية للمعاينة
  وقفل باقي الدروس على المشتركين.
- **متابعة التقدم**: الطالب يعلّم الدروس اللي شافها، ويشوف نسبة إنجازه في كل
  كورس (تتحفظ على الجهاز، ومنفصلة لكل حساب على نفس المتصفح).
- **كمّل من حيث ما وقفت**: المنصة بتحفظ آخر درس اتفتح في كل كورس، وصفحة حسابك
  وصفحة الكورس بيرجعوك له بضغطة واحدة.
- **المفضلة**: قلب على صفحة كل كورس بيحفظه في تاب «المفضلة» في حسابك.
- **صفحة حساب مُعاد تصميمها**: بطاقة تعريف بالصورة الرمزية والصف، وإحصائيات
  (الرصيد، الاشتراكات، الدروس المكتملة، المفضلة)، وتاب لكل قسم.
- **شريط تنقل سفلي للموبايل**: الرئيسية/الكورسات/المحفظة/حسابي في متناول
  الإبهام مع دعم safe-area في الآيفون، وبيختفي على التابلت والكمبيوتر.
- **لوحة تحكم للمالك**: إحصائيات، إدارة كورسات/وحدات/دروس، مراجعة طلبات الشحن،
  وقائمة الطلاب.
- **ثنائي اللغة** (عربي RTL أولًا، وإنجليزي) بواجهة داكنة.

## الستاك

React 19 + Vite + Tailwind v4 + shadcn/ui + wouter · tRPC + superjson + zod ·
Drizzle ORM (Postgres) · Hono · jose/bcryptjs.

## التشغيل محليًا

المتطلبات: Node.js ‏>= 20.19 وpnpm 11 (بيتثبت تلقائيًا عبر corepack)، وقاعدة
Postgres.

```bash
pnpm install
cp .env.example .env        # ثم عدّل DATABASE_URL وJWT_SECRET
pnpm db:migrate             # ينشئ الجداول ويزرع كتالوج البداية
pnpm dev                    # الويب على 3000 والـ API على 3001
```

سكريبتات مساعدة في `scripts/`:

- `pnpm exec node scripts/seed-lessons.mjs` — بيانات دروس تجريبية.
- `pnpm exec node scripts/set-owner-password.mjs` — تعيين/تغيير باسورد المالك.
- `pnpm exec node scripts/attach-posters.mjs` — ربط بوسترات الكورسات.

## أوامر مهمة

| الأمر              | الوصف                                        |
| ------------------ | -------------------------------------------- |
| `pnpm dev`         | تشغيل الويب والـ API معًا في وضع التطوير     |
| `pnpm test`        | كل اختبارات vitest                           |
| `pnpm typecheck`   | فحص TypeScript بدون بناء                     |
| `pnpm build`       | بناء الويب (`dist/public`) والسيرفر (`dist`) |
| `pnpm start`       | تشغيل نسخة الإنتاج المبنية                   |
| `pnpm db:generate` | توليد migration جديدة بعد تعديل `drizzle/schema.ts` |
| `pnpm db:migrate`  | تطبيق الـ migrations على القاعدة             |

## هيكل المشروع

```
client/src/pages,components   واجهة المستخدم
client/src/i18n               النصوص عربي/إنجليزي (المفاتيح متطابقة لازم)
client/src/lib                أدوات العميل (منها progress: تقدم المشاهدة)
server/routers.ts             إجراءات tRPC
server/db.ts                  استعلامات Drizzle (المحفظة، الاشتراكات، الأدمن)
server/_core ، client/_core   منصة جاهزة (auth, storage, serving) — لا تُعدّل
drizzle/schema.ts             الجداول + migrations في drizzle/migrations
shared/                       أنواع وثوابت مشتركة بين العميل والسيرفر
```

## النشر

- **Docker**: الـ `Dockerfile` متعدد المراحل يبني الويب والسيرفر ويشغّل عملية
  واحدة على `PORT` (مناسب لـ Cloud Run وأي استضافة حاويات). لازم تمرّر
  `DATABASE_URL` و`JWT_SECRET` كمتغيرات بيئة.
- **Vercel**: ملف `vercel.json` الحالي ينشر **الواجهة فقط** كموقع ثابت — الـ
  tRPC API والسيرفر مش بيشتغلوا في الوضع ده. للنشر الكامل استخدم Docker أو أي
  استضافة Node، أو حوّل السيرفر لـ Vercel Functions قبل الاعتماد على Vercel.

## ملاحظات

- رصيد المحفظة محسوب من دفتر الحركات (`wallet_transactions`)، مش عمود مخزّن،
  فمفيش احتمال يتكتب رصيد غلط.
- تقدّم مشاهدة الدروس يتحفظ محليًا على جهاز الطالب (localStorage). لو حبيت
  مزامنته بين الأجهزة مستقبلًا، المكان الوحيد اللي هيتغير هو
  `client/src/lib/progress.ts`.
