# مدار

منصة دورات مصوّرة بالعربية. React + TypeScript + Vite + Tailwind 4.

## التشغيل

```bash
npm install
npm run dev        # تطوير على المنفذ 3000
npm run typecheck  # فحص الأنواع
npm run build      # بناء الإنتاج في dist/
```

## هيكل المشروع (Clean Architecture)

```
src/
  app/        تجميع التطبيق والمسارات (App.tsx)
  core/       كيانات مشتركة: Course, Module, Lesson (TypeScript صافٍ)
  data/       بيانات المحتوى التجريبي (catalog.ts) — يُستبدل بالـ API لاحقاً
  modules/
    curriculum/            ميزة المنهج (النموذج الذي ستُنقل إليه باقي الميزات)
      domain/              الكيانات والقواعد: مرحلة/صف/مادة/ترم، فتح الوحدات، نسب الإنجاز — بلا React ولا تخزين
      application/         حالات الاستخدام: إضافة/تعديل/حذف/ترتيب، المسميات، + منفذ الحفظ (ports.ts)
      infrastructure/      التنفيذ الفعلي: localStorage + البيانات الافتراضية. هنا يُستبدل بـ Supabase
      ui/                  CurriculumProvider/useLabels، GradePicker، صفحة السوبر أدمن
    codes/                 أكواد اشتراك يولّدها المدرّس ويفعّلها الطالب (تُخزَّن بصمة SHA-256 فقط)
    analytics/             سلاسل إحصائية تجريبية وحساب الفرق عن الفترة السابقة
    site/                  إعدادات المنصة (الهوية، المدرّس، النصوص، تشغيل/إخفاء الأقسام) بنفس الطبقات
    wallet/                المحفظة والاشتراكات (نفس الطبقات الأربع)
      domain/              الأسعار، قاعدة الوصول canWatchLesson، مدة الاشتراك
      application/         حالات الاستخدام topUp / purchase (دوال نقية) + منفذ الحفظ
      infrastructure/      localStorage للتجربة → يُستبدل بقاعدة بيانات + Paymob
      ui/                  WalletProvider/useWallet، صفحة المحفظة
  features/   teacher و owner (بوابات اللوحات)، enrollment (شاشة الاشتراك)، وباقي الميزات القديمة بالشكل القديم (home, auth, catalog, learning, admin) وستُنقل إلى modules
  shared/     ui, layout, lib (router), styles, studio (هيكل اللوحات: StudioShell، رسوم، جداول)
```

قاعدة الاعتماد: `domain` لا تعتمد على شيء، و`application` تعتمد على `domain` فقط، و`infrastructure` تنفّذ المنافذ، و`ui` تستهلكها.

## المنهج والمسميات

- الهيكل: مرحلة ← صف ← مادة (تتبع المرحلة) ← ترم (اختياري) ← وحدة ← درس. الكورس = مادة لصف معيّن عند مدرّس.
- السوبر أدمن (`admin@madar.app`) يدير كل ذلك من `/owner/curriculum`: أسماء المراحل والصفوف والمواد والترمات، وتفعيل الترمات، وكل المسميات (كورس/وحدة/درس...) بالمفرد والجمع.
- الحذف ممنوع لو العنصر مستخدم في كورسات (قاعدة في `removeItem`).
- الوحدة التالية تُفتح بعد اكتمال السابقة (`isUnitUnlocked`) لو الكورس `sequential`.
- في الواجهة استعمل `useLabels()` و`definite()` بدل كتابة المسميات نصاً. ما زالت نصوص قليلة (لوحة الإدارة والمشغّل) ثابتة.

## البوابات والأدوار

| الدور | الحساب التجريبي | البوابة |
|---|---|---|
| طالب | `student@madar.app` | الموقع (`/`) |
| مدرّس | `teacher@madar.app` | `/teacher`: نظرة عامة، المحتوى، الطلاب، الأكواد، الأرباح |
| مشرف (مساعد المدرّس) | `assistant@madar.app` | `/teacher`: نظرة عامة، الطلاب، الأكواد فقط |

| سوبر أدمن (المالك) | `admin@madar.app` | `/owner`: نظرة عامة، المدرّسون، المنهج والمسميات، المالية، الفريق، طلبات الدعم، إعدادات المنصة |

كلمة المرور للجميع `123456`. المسار القديم `/admin` يوجّه كل دور إلى بوابته. أرقام اللوحات تجريبية.

## الأكواد

- المدرّس أو مشرفه يولّد من `/teacher/codes` دفعة (١–٥٠) لكورس ومدة (شهر/٣ شهور/ترم/سنة). الكود الخام يظهر مرة واحدة فقط.
- الطالب يفعّله من `/redeem`. كل كود لمرة واحدة، والمحاولات الخاطئة المتكررة تُوقف المحاولة ١٠ دقائق.
- في الإنتاج يتم التوليد والتحقق على الخادم (الحدّ من المحاولات والبصمة بملح سرّي).

## الأدوار واللوحات

| الدور | الدخول التجريبي | أين يذهب |
|---|---|---|
| طالب | `student@madar.app` | الرئيسية `/` |
| مدرّس | `teacher@madar.app` | `/teacher` |
| مشرف (مساعد المدرّس) | `assistant@madar.app` | `/teacher` (نظرة عامة، الطلاب، الأكواد فقط) |
| سوبر أدمن | `admin@madar.app` | `/owner` |

كلمة المرور للجميع `123456`. اللوحات بأسلوب YouTube Studio (`shared/studio`): قائمة جانبية على اللابتوب وشريط سفلي على الجوال، أرقام كبيرة مع نسبة التغيير، رسم بياني، وجداول. الأرقام تجريبية (`modules/analytics`).

- **لوحة المدرّس:** نظرة عامة، المحتوى، الطلاب، الأكواد، الأرباح.
- **لوحة السوبر أدمن:** نظرة عامة، المدرّسون، المنهج والمسميات، المالية.
- الدخول لأي لوحة بدون الدور المناسب يعرض رسالة منع.

## أكواد الاشتراك

- المدرّس يولّد دفعة أكواد لكورس ومدة محدّدة (`modules/codes`). الكود الخام يظهر **مرة واحدة** عند التوليد، والمخزَّن بصمة SHA-256 فقط مع آخر ٤ أحرف للتعرّف.
- الطالب يفعّل الكود من `/redeem` فيُفتح له الكورس للمدة بدون خصم من المحفظة. الكود يُستخدم مرة واحدة، ورسالة الخطأ موحّدة لغير الصحيح والمستخدم، مع حد للمحاولات الخاطئة.

## الصلاحيات (الإصدار النهائي)

- **السوبر أدمن حصري للمالك:** الدور `admin` لا يُمنح إلا لإيميل المالك المضبوط في `VITE_OWNER_EMAIL` (`.env.example`). الدور يُبنى من الحساب نفسه وليس من محتوى الجلسة المخزَّنة، فتزوير الدور من المتصفح لا يفيد. والتسجيل بإيميل المالك مرفوض.
- **التسجيل الذاتي ينشئ حساب طالب فقط.** حسابات المدرّس والمشرف وفريق الدعم يُنشئها المالك وحده من `/owner/team`.
- **تسجيل الدخول:** تبويبات اختيار نوع الحساب **مؤقتة للتجربة** (`VITE_SHOW_ROLE_PICKER=true`). عند ربط البيانات اضبطها `false` فيتعرّف النظام على الدور من الحساب تلقائياً بدون أي تعديل آخر في الكود.
- **السنة والترم:** تُحدَّدان عند التسجيل ولا يغيّرهما الطالب. يرسل طلباً من `/support-request`، وفريق الدعم (أو المالك) ينفّذه من `/support` أو `/owner/support`. `AuthProvider.setGrade` يرفض أي تغيير بعد التسجيل، و`applyProfileChange` للدعم والمالك فقط.
- **صفحة التسجيل:** السنوات مجمّعة بالمرحلة في شبكة أزرار متساوية، ثم أقراص الترم، وسطر يلخّص الاختيار (`AcademicPicker`).
- **المظهر:** من `/owner/site` يتحكم المالك في الخلفية واستدارة الملصقات وشكل الأزرار واللون الرئيسي وكل الأقسام والأزرار.

## إعدادات المنصة (السوبر أدمن)

المنصة مجهّزة لتُباع لمدرّس واحد (افتراضياً مدرّس رياضيات للمرحلتين الإعدادية والثانوية). السوبر أدمن يتحكم من `/owner/site` في:

- **الهوية:** اسم المنصة (يتغيّر فوراً في الشعار وعنوان التبويب والفوتر)، والوصف، واللون الرئيسي.
- **المدرّس:** الاسم واللقب والنبذة ورابط الصورة (الاسم والصورة على بطاقات الكورسات يظهران بعد تحديث الصفحة).
- **النصوص والتواصل:** جملة الشريحة الترويجية، ملاحظة الفوتر، الهاتف، واتساب، البريد.
- **الأقسام والأزرار:** تشغيل أو إخفاء كل قسم في الرئيسية (أفضل 10، أول درس مجاني، أحدث الدروس، البطاقة الترويجية، قسم المدرّس، كيفية الاشتراك، الأسئلة، الشريط الأزرق) وأكواد الاشتراك وزرّ جوجل.
- ومن `/owner/curriculum`: المراحل والصفوف والمواد والترمات وكل المسميات.

باقات المدرّس لكل صف (`Course.offering`): «الشرح الكامل»، «المراجعة النهائية»، «حل الامتحانات».

## المحفظة والاشتراك

- الطالب يشحن محفظته بمبلغ، ثم يختار **السنة ← الترم ← المادة ← المدرّس** من `/subscribe` ويُخصم السعر من رصيده.
- السعر للترم الواحد (`Course.termPrice`) ومدة الوصول (`Course.accessDays`). لو الترمات مغلقة يكون الاشتراك لكل الترمات.
- قاعدة الوصول: الدرس المجاني للجميع، وغيره يحتاج اشتراكاً فعّالاً في ترم وحدته (المدرّس والإدارة يرون كل شيء). الشراء المكرر لاشتراك فعّال مرفوض.
- الشحن حالياً **محاكاة**. الربط الحقيقي (Paymob وأكواد الشحن) يتم في `infrastructure` فقط بدون تغيير الـ domain.

## الفيديو

- لكل درس `video` اختياري: `{ kind: 'youtube', id }` أو `{ kind: 'hosted', url }` (`shared/ui/VideoSurface`).
- المقترح: المحتوى المجاني (مثل حلول الواجبات) على يوتيوب، والشرح المدفوع على سيرفر/خدمة استضافة فيديو. المشغّل جاهز للمصدرين، والبثّ المجزّأ (HLS) يُضاف عند اختيار الاستضافة.

## قواعد التصميم

- **لون تفاعلي واحد** أزرق (`--color-accent`) على خلفية سوداء حقيقية `#000000`، والزرار الأساسي كبسولة بيضاء بنص داكن. كل القيم في `tokens.css`. التخطيط مستوحى من Yango Play و Shahid.
- **مقاسات ثابتة:** زرار 48px (52px للأساسي في الجوال)، مساحة لمس 44px، جسم الخط 16px، سطر 1.75.
- **الخط:** Readex Pro (محلي عبر fontsource). لا `letter-spacing` في العربية.
- **نقاط التوقف:** جوال أقل من 768 (شريط تبويب سفلي)، تابلت 768–1023، لابتوب 1024 فأكثر (تنقّل علوي).
- **الرئيسية** بنفس ترتيب صفحات Apple TV (مكيَّفة على هوية مدار):
  - هيدر أسود ثابت: زرّ القائمة (بلون التفاعل)، الشعار في المنتصف، البحث وأيقونة الحساب. القائمة الجانبية فيها كل التنقّل (`TopBar`)
  - `LandingHero` صفحة هبوط بشرائح تُسحب أفقياً (كورسات ثم شريحة ترويجية بجدار ملصقات) مع نقاط وزرّ إيقاف
  - صفوف بعنوان وبجانبه سهم، وملصقات `Poster` بزوايا كبيرة وعنوان في أسفل الصورة
  - `LatestLessonsRail` بطاقات أفقية بمدة الدرس، و`PromoCard` للزائر، و`Top10Rail` بأرقام داخل الملصق
  - `Collections` قوائم بملصقات متراصّة (Plex)، `TeachersRail` المدرّسون، `HowToSubscribe` كيفية الاشتراك
  - `Faq` أسئلة شائعة (Yango Play)، و`GuestBanner` شريط ثابت أزرق للزائر على الجوال، و`Footer` وسطي (Plex)
